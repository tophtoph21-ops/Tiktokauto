# Déploiement GitHub mobile / Railway

Cette édition est préparée pour un dépôt GitHub où les fichiers sont à la racine.

## Depuis ton téléphone

1. Crée un nouveau dépôt GitHub vide.
2. Dans **Add file > Upload files**, sélectionne **tous les fichiers extraits de ce ZIP**.
3. Appuie sur **Commit changes**.
4. Dans Railway : **New Project > Deploy from GitHub repo**.
5. Sélectionne le dépôt.
6. Attends le déploiement.
7. Dans Railway : **Settings > Networking > Generate Domain**.
8. Ouvre l'adresse fournie.

La page d'accueil doit afficher l'interface TikTok Autopilot et non `{"error":"Introuvable"}`.

Important : ne téléverse pas le ZIP lui-même dans GitHub. Décompresse-le d'abord puis envoie tous les fichiers.
